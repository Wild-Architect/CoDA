# CoDA 1.0.0

Перший публічний реліз CoDA для Windows.

## Основні можливості

- готова локальна база державних будівельних норм;
- власні та імпортовані нотатки у форматі `.codanotes`;
- проєкти обміну даними між Archicad 28 та Excel;
- ручна перевірка оновлень програми через меню «Налаштування»;
- автоматична перевірка нової версії під час кожного запуску;
- окремий механізм оновлення бази ДБН.

## Встановлення

Завантажте `CoDA-Setup-1.0.0.exe` і виконайте встановлення. Windows може показати попередження SmartScreen, оскільки перший реліз ще не має комерційного цифрового підпису.

Пакет постачається без нотаток, історії перегляду, закріплених елементів і проєктів користувача. Вбудована база ДБН входить до інсталятора.
