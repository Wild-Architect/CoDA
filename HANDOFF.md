# Передавання проєкту CoDA

## Що це за проєкт

CoDA — настільна програма для роботи з каталогом ДБН, локальними нотатками та обміном даними Archicad / Excel. Поточний інтерфейс реалізований на Electron.

## Запуск на новому комп’ютері

1. Робоча папка проєкту: `D:\CoDA`.
2. Встановіть Node.js LTS (версія 22 або новіша).
3. Відкрийте PowerShell у папці проєкту й виконайте:

   ```powershell
   corepack enable
   pnpm install
   pnpm start
   ```

   Або після `pnpm install` запустіть `start.bat`.

4. Якщо Windows покаже попередження про Electron, дозвольте запуск локальної програми.

## Після перейменування робочої папки

Проєкт підготовлено до перейменування з `D:\EKP BIM tools` на `D:\CoDA`. Робочий код і сценарії використовують відносні шляхи.

Папка `node_modules` містить службові посилання Windows на старе розташування. Після перейменування один раз виконайте в `D:\CoDA`:

```powershell
pnpm install --force
pnpm start
```

Або запустіть `ПІСЛЯ_ПЕРЕЙМЕНУВАННЯ.bat`. Python для Electron-версії CoDA не потрібен.

## Дані ДБН

- Основна локальна база версії `2026.08.09.2` входить до програми: 110 PDF у `building_codes\` та каталог `data\dbn_catalog.xlsx`.
- Базу зібрано з GitHub `fullPackage` і двох опублікованих інкрементальних оновлень; усі пакети й файли перевірено за SHA-256.
- Перший запуск працює без інтернету. Майбутні оновлення завантажуються через manifest і встановлюються у `dbn_database` в каталозі даних користувача CoDA; у dev-режимі — `data\dbn_database`.
- Manifest: `https://raw.githubusercontent.com/Wild-Architect/CoDA-Database/main/manifest.json`.
- Лист Excel: `Каталог ДБН`.
- Обов’язкові заголовки стовпчиків у першому рядку:
  - `Файл ДБН`
  - `Номер ДБН`
  - `Найменування ДБН`
  - `Категорія`
  - `Дата чинності`

Значення в `Файл ДБН` мають точно відповідати назві документа в установленій папці `building_codes`, наприклад `1.pdf`.

## Основні файли інтерфейсу

- `desktop\main.js` — Electron main process, читання Excel і операції з файлами.
- `desktop\preload.js` — безпечний міст між інтерфейсом і файловою системою.
- `desktop\renderer\index.html` — структура вікна.
- `desktop\renderer\style.css` — дизайн.
- `desktop\renderer\scale.css` — корекція масштабу Windows 125%.
- `desktop\renderer\renderer.js` — поведінка інтерфейсу.

## Реалізовано

- світла й темна тема;
- верхня панель із кнопками згортання бічної панелі, назад/вперед, меню та «Про програму»;
- закріплені й нещодавно відкриті нотатки та ДБН у бічній панелі;
- створення, редагування, закріплення й видалення нотаток;
- кілька вкладень до нотатки та окреме відкриття кожного;
- режим адміністратора для формування публічної бібліотеки з вибраних приватних нотаток;
- завантаження версійованої публічної бібліотеки через GitHub у режимі лише для читання;
- відкриття документів ДБН;
- Excel як джерело даних для каталогу.

## Публічна бібліотека нотаток

- Маніфест: `https://raw.githubusercontent.com/Wild-Architect/CoDA-Database/main/notes-manifest.json`.
- Локальна бібліотека користувача: `public_notes_library` у каталозі даних CoDA.
- Інструкція публікації: `CoDA_Cloud_Database\ПУБЛІЧНІ_НОТАТКИ.md`.
- Кожна версія є повним знімком вибраних адміністратором нотаток разом із вкладеннями.

## Важливо перед продовженням роботи

У робочому дереві є значні незакомічені зміни Electron-версії та зібрана локальна база ДБН. Перед перенесенням бажано зробити Git-коміт або перенести всю папку разом із прихованою папкою `.git`.

Для нового чату Codex на іншому комп’ютері надішліть:

> Продовж роботу над CoDA у `D:\CoDA`. Прочитай `HANDOFF.md`, віднови залежності після перейменування командою `pnpm install --force`, перевір запуск, жорстко записані шляхи та стан Git.
