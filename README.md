# CoDA — робоча програма

Настільна програма для роботи з ДБН, локальною Бібліотекою, проєктами та інструкціями ЄДЕССБ, будівельними матеріалами й обміном Archicad/Excel.

## Запуск

1. Встановіть Node.js LTS 22 або новіший.
2. У PowerShell відкрийте папку проєкту й виконайте:

```powershell
corepack enable
pnpm install
pnpm start
```

Або після `pnpm install` запустіть `start.bat`.

CoDA постачається з готовою локальною базою ДБН. Вона зібрана з опублікованого GitHub `fullPackage` та всіх оновлень до версії `2026.08.09.2`, тому перший запуск не потребує завантаження бази.

## Модулі

- **ДБН:** пошук, категорії, посилання ЄДЕССБ і відкриття документа подвійним кліком. Основна база лежить у `building_codes`, а каталог — у `data/dbn_catalog.xlsx`.
- **Бібліотека:** локальні PDF та інші документи у базових і користувацьких категоріях. PDF відкриваються у внутрішньому переглядачі, інші формати — відповідними програмами Windows.
- **Archicad / Excel:** пряме локальне підключення до офіційного JSON API Archicad 28. CoDA створює окремі папки-проєкти, всередині яких можна формувати різні Excel-специфікації. Для кожного проєкту CoDA можна вибрати окремий відкритий екземпляр Archicad, а згодом перепідключити його через список локальних портів або визначити за активним вікном Archicad після п’ятисекундного відліку. Проєкти та окремі внутрішні Excel-файли можна видаляти з підтвердженням. Перший інструмент створює XLSX із усіма елементами, їхніми унікальними ID, ID елементів, слоями та класифікаціями. Після редагування Excel можна імпортувати назад ID елементів і класифікації. Назва слоя через JSON API доступна лише для читання.
- **ЄДЕССБ:** швидкі посилання на сервіси порталу, локальна база проєктів, документів і редакцій, а також вбудований каталог PDF-інструкцій. Каталог лежить у `data/edessb_instructions_catalog.xlsx`, документи — у `edessb instructions`; вони оновлюються тільки разом із програмою.
- **Будівельні матеріали:** категоризований каталог базових і користувацьких матеріалів з унікальними кодами, описами, правилами монтажу та прикріпленими файлами.

## Джерело бази ДБН

- Manifest: `https://raw.githubusercontent.com/Wild-Architect/CoDA-Database/main/manifest.json`.
- Вбудована база є локальною основою версії `2026.08.09.2`.
- Майбутні пакети `updates` повинні починатися від цієї версії та утворювати безперервний ланцюжок до `latestVersion`.
- Кожен пакет перевіряється за розміром і SHA-256, а готова база — за повним переліком `files` із manifest.
