# Публічна бібліотека нотаток CoDA

## Як підготувати бібліотеку

1. У CoDA відкрийте `Налаштування` → `Адміністрування`.
2. Увійдіть за обліковими даними розробника.
3. Позначте приватні нотатки, які потрібно зробити публічними.
4. Вкажіть автора та унікальну версію, наприклад `2026.09.01.1`.
5. Натисніть `Вивантажити бібліотеку нотаток` і виберіть папку.
6. CoDA створить два файли:
   - `CoDA-notes-ВЕРСІЯ.zip`;
   - `notes-manifest.json`.

Кожне вивантаження є повним знімком бібліотеки. Якщо не вибрати раніше опубліковану нотатку, після оновлення вона зникне з публічної бібліотеки користувачів. Приватна оригінальна нотатка при цьому не видаляється.

## Як опублікувати

1. Відкрийте сторінку створення GitHub Release репозиторію `Wild-Architect/CoDA-Database`.
2. Створіть тег `notes-ВЕРСІЯ`, наприклад `notes-2026.09.01.1`.
3. Назвіть Release `Бібліотека нотаток 2026.09.01.1`.
4. Додайте створений ZIP та опублікуйте Release.
5. У корені репозиторію замініть вміст `notes-manifest.json` вмістом файла, створеного CoDA.
6. На іншому комп’ютері відкрийте `Нотатки` та натисніть `Оновити бібліотеку`.

Спочатку публікуйте ZIP, а потім змінюйте маніфест. Не використовуйте одну версію двічі й не змінюйте вже опублікований ZIP.
